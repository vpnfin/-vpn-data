# VPN data from VPNFin

Open data behind the tables on [VPNFin](https://vpnfin.com/): security audits, ownership, prices, device limits, refund windows and VPN laws.

**Last updated: 28 September 2026.**

## How this data is made

VPNFin doesn't run its own speed or leak tests. Each row is compiled from published evidence: audit reports, providers' pricing and help pages, company records and news coverage. The sources for every row are named on the VPNFin page in the `sources_named_on` column.

Values marked `~` are approximate, usually because the provider shows prices in local currency or changes promotions often. Where sources disagree, the row says so instead of choosing one.

## Files

| File | What it contains | Page on VPNFin |
|---|---|---|
| `vpn-audits.csv` | Published no-logs and security audits, auditors, jurisdiction | [VPN audit tracker](https://vpnfin.com/vpn-audits/) |
| `vpn-owners.csv` | Parent company and related brands | [Who owns your VPN](https://vpnfin.com/who-owns-your-vpn/) |
| `vpn-prices.csv` | Introductory price, term, and what the plan renews at | [VPN renewal prices](https://vpnfin.com/vpn-renewal-prices/) |
| `vpn-device-limits.csv` | Simultaneous device limits | [VPNs for multiple devices](https://vpnfin.com/best-vpn-multiple-devices/) |
| `vpn-refunds.csv` | Refund windows and trials without a card | [VPN refunds](https://vpnfin.com/cancel-vpn-refund/) |
| `vpn-laws.csv` | What VPN rules target in 14 countries, and whether they reach the user | [Is a VPN legal?](https://vpnfin.com/is-a-vpn-legal/) |
